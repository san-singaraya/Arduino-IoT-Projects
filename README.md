# Arduino Embedded Systems & IoT Projects

A collection of practical **Arduino embedded systems and IoT projects** developed using **Arduino C/C++ and Wokwi simulation**. These projects demonstrate fundamental concepts of sensor interfacing, digital input/output, LCD communication, I2C communication, and basic automation.
